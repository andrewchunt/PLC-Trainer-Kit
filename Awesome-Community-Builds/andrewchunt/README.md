PLC Trainer Kit – My Community Builds

This repository is a fork of the PLC-Trainer-Kit project created by Oren Niskin / Packets-or-it-didn't-happen.

The original project provides an excellent hands-on platform for learning about Programmable Logic Controllers (PLCs), Human-Machine Interfaces (HMIs), industrial networking, and Operational Technology (OT) cybersecurity using real industrial hardware.

This fork is where I will share my own builds, modifications, and projects based on the PLC Trainer Kit.

🚀 My First Community Build

C-more CM5 Physical HMI Build

My first contribution adds a physical AutomationDirect C-more CM5-T7W HMI to the PLC Trainer Kit.

The original project demonstrates HMI functionality using software-based solutions such as Ignition. I wanted to expand the lab by incorporating a dedicated industrial HMI, providing an experience that more closely represents the type of PLC and HMI interaction commonly found in manufacturing and other OT environments.

The build demonstrates communication between the PLC and C-more HMI and provides physical HMI controls and visualization of the simulated industrial process.
